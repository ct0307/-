# 契鉴企业法务审阅台设计规格

## 目标与边界

在保留 Vue 3、Element Plus、现有接口、权限、路由和业务状态的前提下，把现有卷宗风界面升级为高密度、可信、可追溯的企业法务审阅台。重点服务法务、财务、业务人员和管理员对合同风险的扫描、判断、复核和闭环，不增加营销页面或虚构能力。

## 方案选择

| 方案 | 优点 | 风险 | 结论 |
|---|---|---|---|
| 仅调整颜色与圆角 | 改动小 | 无法解决审查页层级和证据可信表达 | 不采用 |
| 连续工作台与证据链轨道 | 保留现有流程，同时提升任务层级和专业性 | 需要重排核心模板与样式 | 采用 |
| 合同原文分屏编辑器 | 审阅体验最强 | 需要新增全文定位与编辑能力，超出当前接口 | 不采用 |

## 视觉系统

- 页面底：`#f2f4f7`，工作表面：`#ffffff`，次级表面：`#f7f8fa`。
- 主文字：`#202838`，次级文字：`#475467`，弱文字：`#667085`。
- 黄铜 `#8a6a1c` 仅用于品牌、选中状态和主操作。
- 印章红 `#b42318` 用于高风险和阻断；琥珀 `#b54708` 用于中风险和待复核；合规绿 `#137a54` 用于通过和闭环。
- 一级标题与“契鉴”保留中文衬线字体；正文、表格、控件使用中文无衬线字体；编号、时间、置信度使用等宽数字。
- 圆角最大 8px；普通容器使用 1px 边线和极轻阴影；抽屉和弹窗才使用明显层级阴影。
- 不使用渐变、玻璃拟态、装饰光效、卡片嵌套或无语义胶囊标签。

## 应用框架

- 侧栏保持 264px/64px 两态和移动端 overlay；品牌、导航、算力、身份被组织成单一纵向框架，不再像四张独立卡片。
- 顶栏高度收紧，底边由 2px 黄铜线改为中性边线加短黄铜识别线。
- 主内容宽度保持 1600px 上限，桌面端间距更紧凑，移动端保持 16px 安全边距。

## 核心审查工作台

- 左侧 360px 为合同接入和审查配置，右侧为连续结果工作面。
- 空状态的三步流程改为横向任务轨道，突出当前步骤，不占据大面积卡片。
- 审查完成后，文件身份、人工复核警告、状态数据、风险列表和合同要素按任务顺序排列。
- 每条风险展示等级、类别、复核状态、建议摘要以及证据状态：有来源显示来源数量，无来源显示“无可靠依据 · 待人工复核”。
- 风险复核抽屉建立五段证据链：命中原文、法规/规则依据、检索来源、修改建议、人工处置。无来源时必须显示明确警告，不留空白。

## 其他页面

- 仪表盘和报表保留数据与图表，使用开放 KPI 行和一致的面板标题、边线、数字格式。
- 历史记录、整改、管理页优先使用紧凑表格和列表；固定操作区域，数字右对齐。
- 知识库卡片降级为知识条目列表/网格，并用明确状态区分 global、scoped、unclassified。
- 规则、模板和管理配置使用相同的工具栏、计数、空状态和危险操作表达。

## 响应式与无障碍

- 1440x900 与 1920x1080 保持双栏工作台；1180px 以下单列；390x844 无横向溢出。
- 移动端侧栏默认隐藏，打开后聚焦激活项，Escape 可关闭。
- 高中低风险同时使用文字、色条和状态名称，不只依赖颜色。
- 保留 `focus-visible`、ARIA、键盘操作与 `prefers-reduced-motion`。

## 验收

- `npm run type-check`、`npm run build`、`npm test` 全部通过。
- 浏览器检查页面身份、非空、无框架覆盖层、Console 无应用错误、核心交互和桌面/移动端截图。
- 对比基线截图与最终截图，至少检查布局、排版、颜色、容器、风险语义和响应式六项。
