# AI角色模拟复核协议

用户于2026-10-31要求由助手分别代入法务、财务完成复核标注。交付为AI辅助候选及探索分析，不是独立真人专家金标。

1. 只读取既有20份冻结脱敏测试合同；法务和财务分别阅读全文，各自产出有原文依据的风险、理由、建议及不确定项。相互不可见，也不向标注阶段提供三组模型预测。
2. 在读取模型预测前，合并两类角色候选，核对完整正文与附件，明确排除已被后签专门约定消解的冲突。冻结AI参考及散列。原文不匹配的候选保留为不确定项，不计入可匹配参考。
3. 对原始180单元的每条输出进行组别隐藏裁决。完全相同的“合同+类别+原文+问题”可复用裁决，修改建议不在本轮正确性评价范围。裁决输入没有组别、重复轮次、来源角色、请求状态或组别汇总。
4. 裁决区分匹配参考、原文不支持、支持但参考未收录的新候选、不确定及未成功裁决。新候选不直接当误报，也不为单组补充参考。所有待定项进入复核清单。
5. 按每个单元对同一参考问题只计一次覆盖；失败单元和部分结果全部保留。报告AI参考覆盖率及原始裁决分布，不将它们称为法律准确率或真人召回率。不计算未获独立人工标签支持的Precision/F1。
6. 角色标注、合并与裁决均使用当前已授权的gpt-6.1-sol服务，最多3请求并发，温度0；每项最多2次尝试，所有尝试留痕。仅本进程授权既有yorhamc.com目的地，不写入.env白名单。失败保留，不伪造结果。
7. 同一模型担任被测系统与裁判，存在自评偏差；角色隔离不等于独立专家。合成模板、小样本及事后评价限制继续适用。人工金标、人工盲评及原报告中的未测量状态保持不变。

交付：两套原始角色标注、合并候选参考、全部输出裁决、逐单元覆盖与遗漏、待核验清单、完整调用记录、Word报告和可复现说明。所有含合同或运行内容的文件保存于本地outputs忽略目录。
