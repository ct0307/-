本轮在既有 FastAPI、Vue、任务队列与窗口检查点上增量改进，保留仓库原有未提交变更。未安装依赖，未迁移 LangGraph，未提交、部署或修改 CI/CD。

## 已实现范围

| 优先级 | 问题 | 当前行为 |
|---|---|---|
| P1 | 失败或未完成审查被空风险列表误导 | 历史台账将失败、未审查、进行中、覆盖不足标为“尚无法判断”；完整成功且零候选才显示“未发现风险” |
| P1 | 旧任务风险或完整度混入当前任务 | 候选按任务隔离，兼容零代旧任务；详情依据当前快照的状态、覆盖率和质量信息判断，缺字段时降级 |
| P1 | 原文阅读器只显示风险摘录 | 新增授权正文接口，读取有效解析缓存；保留正常条款和附件，精确匹配引用，未匹配明确提示人工核对 |
| P1 | 切换合同时旧请求覆盖新结果 | 正文、详情及已完成审查加载具有取消或版本保护，旧响应不能覆盖新选择或清除新请求的加载状态 |
| P1 | 错误原因不准确 | 模型禁用返回 `MODEL_DISABLED`，出站策略阻止返回 `MODEL_OUTBOUND_BLOCKED`，两者不提供无效的直接重试 |
| P2 | 快窗口等待慢窗口才报告进度 | 工作线程只计算，调用线程按完成顺序写检查点并回调进度；最终结果仍按源窗口顺序返回，不增加并发和调用预算 |
| P2 | 主要操作不突出 | 上传入口前置、空交接区收紧；风险卡和历史合同名支持键盘操作；正文桌面双栏、窄屏纵向 |
| P2 | 缺少一致性能统计口径 | 扩展既有离线 CLI，提供阶段均值/P50/P95及采集覆盖，缺失数据保留未知，人工复核率单列 |

正文接口 `GET /api/v1/contracts/{contract_id}/document` 限法务、财务及管理员，执行部门隔离、软删除检查和有效缓存校验，返回 `Cache-Control: no-store`，不暴露存储路径、不重新解析或调用模型。正文采用文本插值渲染。
