## 独立 LangGraph 原型

源代码位于 `backend/integration/langgraph_pilot/`，入口与正式服务分离。使用 LangGraph 1.2.19 和 SQLite checkpoint 3.1.3，40 个锁定依赖仅安装在 `outputs/langgraph-evaluation-20261101/prototype-venv/`。正式 backend/.venv 及 requirements 未加入 LangGraph。

原型实现：单窗口单角色的分页发现、逐条补充、已关联冲突的一次复核、人工中断与授权恢复、候选快照及业务发布替身。具备持久预算、绝对时限、身份/执行权围栏、未知外部调用占用保留，以及业务任务/代次维度幂等发布。

对模型输出和数据库写入做故障注入后，修复了三项原型问题：发布不能只按图线程去重；复核 verdict 必须先验证类型；图检查点必须同步保存，且保存成功后才能记录 committed 与增加完成数。检查点成功但事件记录失败时，恢复入口可按检查点 ID 补记，不重复调用或发布。

人工权限、角色、时间和响应均为隔离夹具。上述能力不能表述为已接入真实业务审批、已提升法律准确率或正式服务已支持图级重启恢复。
