# 请求隔离、追问与模型出站加固

> 本文保留 2026-10-30 的加固与验收记录。2026-11-01 已在合同审查业务层增加请求内临时脱敏和结果标记还原，底层目的地授权及敏感载荷拒绝检查继续生效；详见[审查反馈修复验收](engineering-hardening/audit-feedback-acceptance.md)。此更新不代表所有业务入口或所有敏感字段均支持脱敏。

## 行为变化

- 风险切换、抽屉关闭和组件卸载后，旧请求不再修改消息、错误或加载状态。
- 导入轮询停止或重置后，旧响应不再恢复批次；旧失败不停止新的轮询。
- 上传未完成时重置收件箱，迟到的上传结果也不会恢复批次或修改新操作的加载状态。
- 追问为独立问答，不发送客户端历史。模型须返回结构化结果，引用必须属于当前授权风险的已核验依据；无效结构、引用、新增明确法规标题/条号/数值或截断回答转为人工复核。
- 单次追问输入上限 24000 字符、输出预算 700 token；这些是单次预算，不是用户级调用频率限制。
- 引用和格式校验不证明法律语义正确，所有回答仍需人工复核。
- PostgreSQL 行锁显式限定批次项表，避免 eager LEFT JOIN 的可空侧触发数据库错误；合同锁顺序保持不变。

## 模型出站配置

移除代码和示例配置中的默认第三方中转地址。外部模式需要企业明确授权目的地：

```dotenv
MODEL_PROCESSING_MODE=external_model
LLM_BASE_URL=https://approved-provider.example/v1
MODEL_EXTERNAL_ALLOWED_BASE_URLS=["https://approved-provider.example/v1"]
```

示例地址不可用，必须由管理员填写实际批准的地址。未授权会阻止模型调用；本次不会修改真实 `.env`。

聊天和向量化在同一适配器出站口检查目的地，并关闭环境代理和自动重定向。检测到已知手机号、身份证、长账号、邮箱和部分带标签的姓名/地址等字段时，外部调用直接拒绝，避免替换原文后破坏审查定位。请使用私有模型或人工复核处理此类合同。

私有模式继续要求显式私网/回环 IP。已知敏感字段识别并不完整，无法覆盖所有姓名、商业秘密和地址；目的地授权不等于所有合同已获外传许可。业务角色输出增加递归字段脱敏，完整审查角色保留其授权显示权限。

## 单独运行生产服务集成验收

默认质量门禁不会访问生产服务。准备专用测试 PostgreSQL 和 Redis 后，在 backend 目录显式运行：

```powershell
# 通过当前进程环境配置连接，不提交凭据。仅支持 postgresql+psycopg。
# QIJIAN_TEST_POSTGRES_URL：库名必须以 _test 结尾。
# QIJIAN_TEST_REDIS_URL：必须显式指定非 0 号专用测试库。
.\.venv\Scripts\python.exe -m pytest integration/test_production_services.py -q
```

验收创建随机 schema 和 Redis 队列前缀，仅清理本次 schema 与任务结果，不清理 public、不执行 flushdb。它验证真实 PostgreSQL 行锁竞争、实际 Celery 任务经 Redis 重复投递时的租约排他；模型审查使用合成桩，不进行真实模型调用。

这不是完整生产压测，也不覆盖进程崩溃重投、OCR 准确率、法律准确率或真实合同集性能。缺少服务配置时明确失败，不把跳过写为通过。
