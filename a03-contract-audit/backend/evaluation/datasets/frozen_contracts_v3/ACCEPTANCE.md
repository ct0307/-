# 高拟真合成冻结合同集 v3 验收记录

## 验收结论

v3 可作为企业合同审查系统的高拟真合成冻结测试集。合同正文、交易事实、附件、签署结构、文档形态和异常输入均按现实企业合同习惯构造，没有为当前解析器集中或简化字段。

本结论不表示这些文件可直接作为签约模板，也不表示其已经成为法律金标准。全部主体和业务记录均为合成信息；投入真实企业验收前，仍需以经授权、脱敏的真实合同补充验证，并由具备对应行业经验的法务人员完成双人独立标注和分歧裁决。

## 真实性审查

- 合同覆盖采购供货、技术软件、运维咨询、租赁、建设工程、人力服务、数据与知识产权、框架订单等常见交易。
- 正文按各条款的法律功能分别构造，并包含交易范围、价税付款、交付验收、变更、数据与知识产权、责任救济、期限退出、治理通知等机制。
- 长合同包含项目治理、授权边界、履约台账、依赖升级和退出交接；短式订单保留与单次交易相称的结构。
- 附件采用业务项目、计量单位、指标、系统证据、责任角色和补救规则等具体值。代表案例已专项核查机床、视觉检测、光伏、仓配、车辆租赁及洁净工程的字段组合。
- PDF 保留文本、扫描和混合形态；扫描样本含轻微旋转、对比度衰减和边缘阴影，但不伪造真实印章、签名或企业身份。

## 残余风险

1. 合同虽接近现实成稿结构，但仍是程序化合成文本，不能覆盖真实交易中的历史谈判、公司制度、地方监管口径和行业惯例差异。
2. 14 份 DOCX 尚缺真实办公软件逐页视觉复核；36 份 PDF 中只有 4 份代表样本完成人工视觉抽检。
3. 纯扫描 PDF 的 OCR 能力、真实模型 API、PostgreSQL、Redis/Celery、OpenClaw/GPU 和能耗均未在本轮实测。
4. `gold-review-template.jsonl` 保持 `pending_human_review`，不得将构造真值宣传为真人法务金标准。

## 企业使用前置条件

- 引入经授权且完成脱敏的真实合同样本，按合同类型、格式、风险层级和扫描质量分层抽样。
- 由业务法务与行业律师双人独立复核，明确适用法律、版本日期、公司制度和可接受风险阈值。
- 在目标生产栈中重跑 OCR、解析、批量任务、数据库和安全控制测试，并保留失败样本及审计记录。
- 合同模板如用于签署，必须另行经过企业法务、财税和业务负责人审批，不得从本测试集直接投产。
